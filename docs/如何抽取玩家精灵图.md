# 如何抽取玩家精灵图

与怪物不同：角色由 **身体 / 头 / 脸 / 头发 / 装备** 多层拼装，客户端只有各部件图集，没有现成的「整人 stand_0.png」。

本仓库做法：

| 产物 | 来源 | 用途 |
|------|------|------|
| `stand1_*.png` / `walk1_*.png` 等完整立绘 | [maplestory.io](https://maplestory.io) `GMS/83` Character **合成** | 数据集贴图、标注首选 |
| `atlases_from_game/` | 客户端 `SpriteSheet/CN/Character/...` | 原始部件图集备份 |
| `parts_from_game/`（可选） | 客户端图集 + IO item frameBooks NCC 裁切 | 需要单部件帧时 |

安装路径见仓库根目录 `安装位置.txt`。

## 为什么整人不能像怪物那样裁？

- 怪物：一张 `Mob/{id}_0.png` 图集里就是完整帧 → NCC 可直接裁。  
- 玩家：身体 `00002000`、头 `00012000` 等 **不是** 可下载的独立 item；装备才是 item。  
- `*.wzspritesheet` 多为加密，读不出矩形。  
- 因此「整人」走 IO：`/Character/{skin}/{itemIds}/{anim}/{frame}`；部件图集仍从客户端导出。

## 合成立绘 API

```text
GET https://maplestory.io/api/GMS/83/Character/{skin}/{items}/{animation}/{frame}
```

- `skin`：如 `2000`（浅肤；身体键 `00002000`，头键 `00012000`）  
- `items`：逗号分隔装备 ID，如 `20000,30000,1040002,1060002,1072001`  
- `animation`：`stand1` / `walk1` / `jump` / `alert` …  
- `frame`：从 `0` 起  

查装备中文/英文名：

```text
GET https://maplestory.io/api/GMS/83/item/{id}/name
```

## 客户端部件路径

```text
Assets/WzAssets/SpriteSheet/CN/Character/00002000_0.png          # 身体
Assets/WzAssets/SpriteSheet/CN/Character/00012000_0.png          # 头
Assets/WzAssets/SpriteSheet/CN/Character/Face/{id:08d}_0.png
Assets/WzAssets/SpriteSheet/CN/Character/Hair/{id:08d}_0.png
Assets/WzAssets/SpriteSheet/CN/Character/Coat|Longcoat|Pants|Shoes|Weapon/...
```

在 `StreamingAssets/aa/w/spritesheet_*.bundle` 中搜索 `00002000_0.png` 即可定位 Character 包。

## 脚本用法

```powershell
cd mxd_tools
pip install UnityPy Pillow numpy opencv-python

# 抽出全部预设（立绘 + 图集；不含部件裁切）
python .\scripts\extract_sprites.py --player

# 只抽指定预设
python .\scripts\extract_sprites.py --player 默认女新手 男战士 男魔法师

# 额外 NCC 裁切脸/发/衣等部件（慢，一般标注不需要）
python .\scripts\extract_sprites.py --player 默认男新手 --player-parts
```

输出根目录默认 `mxd_tools/assets/player/{预设名}/`。

每个预设目录典型内容：

```text
stand1_0.png … stand1_3.png
walk1_0.png … walk1_3.png
jump_0.png
alert_0.png …
atlases_from_game/     # body/head/装备图集
README.txt
```

**数据集贴图请优先用 `stand1_0.png`。**

## 自定义一套外观

在 `scripts/extract_sprites.py` 的 `PLAYER_PRESETS` 里加一项即可，例如：

```python
"我的号": {
    "skin": 2000,
    "items": [20000, 30000, 1040002, 1060002, 1072001],
    "desc": "说明文字",
},
```

或临时用浏览器/脚本直接请求 Character URL，把 PNG 存进 `assets/player/...`。
