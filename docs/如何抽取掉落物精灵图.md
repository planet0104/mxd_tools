# 如何抽取掉落物精灵图

击杀怪物后地上的金币、药水、材料、装备、武器等图标，可从客户端图集裁出，放到 `assets/drops/`。

## 用法

```powershell
cd mxd_tools
pip install UnityPy Pillow numpy opencv-python

# 默认清单（金币 + 常用药水/材料/武器/装备）
python .\scripts\extract_sprites.py --drops

# 指定物品 ID
python .\scripts\extract_sprites.py --drops 2000000 1302000 4000000
```

## 输出

```text
assets/drops/
  README.txt
  金币/          # Item/Special/0900 拆帧（硬币、钱袋等）
  药水/          # 红/橙/白/蓝药水、神水、苹果等
  其他/          # 蜗牛壳、蘑菇盖、树枝等
  武器/          # 剑/斧/弓等 icon
  装备/          # 衣服/鞋/盾等 icon
```

文件名形如：`2000000_红色药水.png`、`meso_00.png`。

## 原理

| 类型 | 客户端图集 | 裁切方式 |
|------|------------|----------|
| 金币 | `Item/Special/0900_0.png` | 连通域拆帧 |
| 药水/材料 | `Item/Consume/02xx_0.png`、`Item/Etc/04xx_0.png` | IO `iconRaw` 模板 NCC 对齐裁切 |
| 武器/装备 | `Character/{Cap,Coat,Weapon,...}/0xxxxxxx_0.png` | 同上（地上掉落外观=背包图标） |

像素始终来自客户端；[maplestory.io](https://maplestory.io) `GMS/83` 只提供图标参考与命名。

安装路径见仓库根目录 `安装位置.txt`。
