# 如何查找并下载完整地图 PNG

本文记录「彩虹岛 · 南港西郊平原」一例的实际查找过程，以及可复用的下载脚本。

## 结论摘要

| 项目 | 内容 |
|------|------|
| 中文名 | 彩虹岛 / 南港西郊平原 |
| 英文名 | Maple Road / The Field West of Southperry |
| 地图 ID | **50001** |
| 完整图来源（英文） | [maplestory.io](https://maplestory.io) **`GMS/83`** `/render` |
| 中文完整图 | 本地拼图：`scripts/extract_map_cn.py`（布局用 GMS WZ，木牌用客户端 CN 图集） |
| 游戏安装目录 | **没有**现成的完整图 PNG |

怀旧服客户端（Unity）里的地图是 Addressables 中的 `000050001.wzjson` 等数据，运行时拼图，不会落一份「整图 PNG」在磁盘上。

## 语言说明（木牌文字从哪来）

木牌、路牌上的字是 **画进 Map/Obj 精灵里的**，不是运行时按语言表刷的。

| 来源 | 地名 API | 整图 | 木牌文字 |
|------|----------|------|----------|
| `GMS/83` `/render` | 英文 | ✅ | **英文**（Southperry） |
| `CMS/148` `/render` | 中文 | ❌ `50001` 404 | — |
| `extract_map_cn.py` | — | ✅ 本地拼 | **中文**（南港，来自客户端 CN 图集） |

## 能否从客户端自己拼中文图？

| 目标 | 现状 |
|------|------|
| 中文 **minimap** | ✅ `scripts/extract_minimap.py` |
| **完整大地图**（英文木牌） | ✅ `scripts/extract_map_render.py` |
| 中文 **完整大地图** | ✅ `scripts/extract_map_cn.py` |

`extract_map_cn.py` 做法：

1. **布局**（tile/obj/back 坐标）：`maplestory.io` WZ API `GMS/83`（与怀旧服同图几何）
2. **像素**：Tile / Back / 普通 Obj → GMS WZ canvas；**signboard** → 客户端 `SpriteSheet/CN/Map/Obj/signboard_*.png`，用英文板轮廓匹配中文帧
3. **背景 type 1/2/3** 按水平/垂直/双向平铺

本例输出：`assets/maps/50001/map_50001_render_cn.png`（约 `2040×1483`，木牌为「南港」）。

详见：`如何从客户端导出minimap.md`。

## 当时用的查找步骤

### 1. 从游戏截图读线索

截图左上角小地图标题：

- 一级：`彩虹岛`
- 二级：`南港西郊平原`

画面中的 NPC：`白瑞德`（国际服 Bari）。

### 2. 用 NPC / 中文名反查地图 ID

Biligame wiki 对「南港西郊平原」可能搜不到条目（短 ID、命名不一致时常见）。

改用mxd资料站按 NPC 查：

- 打开 [mxd.dvg.cn 白瑞德](https://mxd.dvg.cn/npcsinfo.php?id=20001)
- 出没地区写明：`彩虹岛 南港西郊平原 (50001)`

得到 **地图 ID = 50001**。

### 3. 用 maplestory.io 核对英文名

```text
GET https://maplestory.io/api/GMS/83/map/50001/name
```

返回：

```json
{
  "name": "The Field West of Southperry",
  "streetName": "Maple Road",
  "id": 50001
}
```

与「南港西郊平原」语义一致，可确认 ID 正确。

### 4. 下载小地图画布 + 完整渲染图

```text
GET https://maplestory.io/api/GMS/83/map/50001/minimap
GET https://maplestory.io/api/GMS/83/map/50001/render
```

本例尺寸大约：

- minimap：`125×72`
- render：`1909×956`

保存到 `mxd_tools/tmp/map_50001_minimap.png`、`map_50001_render.png`。

### 5.（可选）在游戏目录里确认有没有本地 PNG

安装路径见仓库根目录 `安装位置.txt`，例如：

`D:\Program Files\上海数龙科技有限公司\mxdonline\mxdclassic`

检查结果：

- 根目录与 `Maplestory_Classic_Data` 下 **0 个** 散落 `.png` 地图
- 资源在 `StreamingAssets\aa\` 的 Addressables bundle 里
- `catalog_json.bin` 中能搜到 `00050001.wzjson`（地图数据，不是完整渲染图）

因此：**查 ID → 从 maplestory.io 下 PNG** 才是拿到「完整地图图」的实用路径。

## 推荐工作流（以后照做）

```mermaid
flowchart TD
  A[截图: 一级/二级地图名 + NPC] --> B{已有数字 ID?}
  B -->|是| D[maplestory.io /name 核对]
  B -->|否| C[wiki 解析名 → ID]
  C -->|失败| E[mxd.dvg.cn 用 NPC/地图名查 ID]
  E --> D
  D --> F[下载 /minimap 与 /render]
  F --> G[写入 mxd_tools/tmp]
```

1. 优先记下 **地图 ID**（最稳）。
2. 没有 ID 时：先试 biligame wiki 标题/搜索；再试资料站 NPC。
3. 用 `/name` 确认后下载 `/minimap`、`/render`。
4. 不要指望在 `mxdclassic` 安装目录里直接找到完整图 PNG。

与本仓库工具的关系：

- **定位玩家**：YOLO 检测「玩家」框 + 左右移动残差确认自身（`SelfTracker`）；不依赖小地图黄点
- minimap / render 资源仍可用于地图浏览、数据集标注等
- 国服中文名 → ID 目前主要靠 wiki；像 `50001` 这种短号，wiki 不一定有，需要 ID 或资料站兜底

## 脚本用法

### 是否支持任意地图名？

| 入口 | 输入 | 说明 |
|------|------|------|
| App「提取小地图与完整图」 | 中文名或数字 ID | 经 wiki 解析 ID，再下 GMS minimap + render |
| `cargo run --bin download_map -- 南港` | 中文名或 ID | 同上 |
| `python scripts/extract_minimap.py 50001` | **仅数字 ID** | 客户端 CN minimap |
| `python scripts/extract_map_cn.py 50001` | **仅数字 ID** | 中文木牌本地拼图（首次会拉 WZ 布局/精灵） |
| `python scripts/extract_map_render.py 50001` | **仅数字 ID** | GMS 英文完整图 |

中文名解析依赖 biligame wiki；短号图（如 `50001`）wiki 可能搜不到，此时请直接填 **数字 ID**。

### App / Rust：按地图名提取

App 中填写地图名后点「提取小地图与完整图」，或：

```powershell
cd mxd_tools
cargo run --bin download_map -- 彩虹岛-南港西郊平原
cargo run --bin download_map -- 50001
```

### Python：中文完整大地图（需数字 ID）

```powershell
cd mxd_tools
python -u scripts/extract_map_cn.py 50001
```

输出（默认 `assets/maps/50001/`）：

- `map_50001_layout_wz.json` — 布局缓存（首次拉取较慢，之后复用）
- `map_50001_render_cn.png` — 中文木牌完整图
- `map_50001_render_cn.json` — 元数据

需本机已安装游戏客户端（读 CN signboard 图集），以及 `opencv-python` / `Pillow` / `numpy`。

### Python：GMS 英文完整图 + WZJS 元数据

```powershell
cd mxd_tools
python scripts/extract_map_render.py 50001
```

输出：

- `map_50001_render.png` — GMS 完整图（约 `1909×956`，木牌英文）
- `map_50001_render.json` — 地名 API + WZJS portal/VR/miniMap

### PowerShell / Rust（仅下载）

```powershell
cd mxd_tools
.\scripts\download_map.ps1 -MapId 50001
cargo run --bin download_map -- 50001
```

输出文件：

- `tmp/map_{id}_minimap.png`
- `tmp/map_{id}_render.png`
