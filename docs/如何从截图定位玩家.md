# 从完整窗口截图定位玩家

游戏窗口左上角是小地图 UI；内容区可能完整显示，也可能只是滚动视口。玩家为菱形黄点（中心约 `#FFFF88`，边缘约 `#FFFF00`）。不同分辨率下 UI 像素尺寸会变，因此用 **minimap 画布多尺度 `matchTemplate`** 找内容区。

实现：`src/minimap_match.rs`（**OpenCV 静态链接**，对齐 `scripts/locate_from_screencaps.py`）。安装见 `docs/如何静态链接OpenCV.md`。

## 算法

1. 在截图左上约 48%×58% 区域搜索  
2. 对 `map_*_minimap.png` 做多尺度 `TM_CCOEFF_NORMED`（mask 掉画布纯黑、搜索区黄点置 0）  
3. 在匹配框内找黄色菱形；若落在天空则向下吸附草地，否则用菱形底边  
4. **画布 → 完整大地图**（`CanvasToFullAlign`，不可直接按宽高比线性缩放，完整图常有额外天空）：  
   - 先把大地图 **缩到与小地图同宽**（同尺度再匹配；SIFT/ORB 在尺度差过大时不可靠）  
   - 两边再 ×3，**SIFT + FLANN**（Lowe 0.8）+ RANSAC 单应，再按缩放因子映回原图  
   - 失败则回退：同尺度剪影 `matchTemplate`；再失败则内容带 Y 映射  
5. 若整图画布匹配分低于 0.42：回退经典视口比例再对齐画布

cd mxd_tools
# 需已完成静态 OpenCV 安装（含 features2d / calib3d / flann）
cargo run --release --bin validate_screen_caps -- `
  --caps screen_caps/彩虹岛-南港西郊平原 `
  --minimap assets/maps/50001/map_50001_minimap.png `
  --full assets/maps/50001/map_50001_render_cn.png
