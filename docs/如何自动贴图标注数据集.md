# 自动贴图标注生成 YOLO 数据集

依据 `dataset/<图名>/需要自动贴图标注的部分说明.txt`：

1. 保留已标好的地板 / 梯子 / 绳子  
2. 在完整大图地板上随机贴入口、出口、花蘑菇、蓝蜗牛、树怪、玩家  
3. 生成多张大图副本（中间结果）  
4. 再按游戏窗口比例随机裁切  
5. 按比例在部分窗口上贴 UI（仅窗口层，不贴大地图）→ **最终 YOLO 训练数据**

## 用法

```powershell
cd mxd_tools
pip install Pillow

python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原
```

常用参数：

```powershell
python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原 `
  --full-maps 50 `
  --crops-per-map 14 `
  --ui-ratio 0.65 `
  --players-min 5 --players-max 6 `
  --climbers-min 2 --climbers-max 4 `
  --snails-per-large-min 3 --snails-per-large-max 4 `
  --stumps-per-large-min 2 --stumps-per-large-max 3 `
  --seed 42
```

默认约 **50×14 ≈ 700** 张窗口图（再按 15% 划 val）。上次若只有四百来张，是旧默认 `40×12`；现已提高。`--ui-ratio 0.65` 表示约 65% 带 UI、35% 无 UI。

## 大概需要多少张？

这类「固定地图风格 + 合成贴图」的 YOLO 检测：

| 目标 | 建议窗口图数量（单图场景） |
|------|---------------------------|
| 冒烟能检出 | **200~500** |
| 实用可用（推荐起步） | **800~2000** |
| 更稳、少漏检 | **3000+**，并加真实截图混训 |

注意：合成图再多也代替不了少量**真实游戏截图**（光照、UI、压缩、遮挡）。可先合成 1k 左右把模型跑通，再混入几十~几百张真实标注窗提高泛化。

加大产量示例：

```powershell
python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原 `
  --full-maps 80 --crops-per-map 15
```

约 1200 张窗口样本。

训练模型见：`docs/如何训练YOLO模型.md`（`scripts/train_yolo.py`）。

## 默认密度

| 对象 | 规则 |
|------|------|
| 玩家 | 每张大图 **5~6** 个（地板）+ **2~4** 个攀爬（绳子/梯子） |
| 蓝蜗牛 | 每块**大地板** **3~4** 只；小地板偶尔补 0~1 |
| 树怪 | 每块大地板 **2~3** 只；小地板与蜗牛二选一偶尔补 |
| 花蘑菇 | 每块大地板 **1~2** 个 |
| 入口/出口 | 每张大图 **3~5** 个（互不重叠） |
| UI | 裁切后的窗口上按 `--ui-ratio` 贴入（默认 65%） |
| 精灵互遮 | 任意两个贴图精灵互相覆盖面积 **≤ 60%**（允许轻度重叠，禁止几乎完全挡住） |

贴怪顺序：花蘑菇 → 树怪 → 蓝蜗牛（先大后小）。攀爬帧来自 maplestory.io 的 `ladder` / `rope` 动画（背部姿势）。若资源缺失会回退为正面帧仍贴到绳子/梯子上。重新抓取：

```powershell
python .\scripts\extract_sprites.py --player
```

每次贴图都会从对应目录 **随机选一帧**（如 `move_2.png` / `stand1_1.png` / `pv_03.png`），怪和玩家再 **50% 概率水平翻转**。labelme 的 `description` 会记下 `frame=...`。

大地板判定：宽 ≥ 200 或面积 ≥ 15000。

## 窗口 UI 布局（只贴在裁切窗上）

资源目录：`assets/ui/`

| 元素 | 位置 |
|------|------|
| 小地图 | 窗口左上角 |
| 任务窗 | 右上角附近（轻微抖动） |
| 浮动按钮 | 窗口左侧竖直居中 |
| 面板 | 窗口底部居中 |
| 键盘 | 面板上方、与面板右缘对齐紧贴（不遮挡面板） |

窗口过窄时整套 UI 会等比缩小。带 UI 的文件名带 `_ui` 后缀。

## 输出

默认写到 `dataset/<图名>/generated/`：

```text
generated/
  full_maps/          # 中间：完整大图 PNG + labelme JSON（无 UI）
  yolo/
    data.yaml
    classes.txt
    images/train|val/
    labels/train|val/
  README.txt
```

类别顺序（`data.yaml`）：

`地板, 梯子, 绳子, 入口, 出口, 花蘑菇, 蓝蜗牛, 树怪, 玩家, 小地图, 任务窗, 浮动按钮, 面板, 键盘`

窗口尺寸参考 `screen_caps/<同名>/` 首张截图，并附加多种缩放比例。

## 依赖资源

- 大图：`dataset/.../map_*_render*.png` + 同名 `.json`（已含地板等）  
- 精灵：`assets/portals/pv_*`、`assets/mobs/1210102_花蘑菇`、`assets/mobs/100101_蓝蜗牛`、`assets/mobs/130100_树怪`、`assets/player/*`  
- UI：`assets/ui/*_UI.png`
