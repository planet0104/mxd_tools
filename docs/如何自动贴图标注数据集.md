# 自动贴图标注生成 YOLO 数据集

依据 `dataset/<图名>/需要自动贴图标注的部分说明.txt`：

1. 保留已标好的地板 / 梯子 / 绳子  
2. 在完整大图地板上随机贴入口、出口、怪、掉落物、玩家  
3. 大地板混合四种模式：正常 / 稀疏 / 仅掉落 / 空台  
4. 生成多张大图副本 → 按窗口裁切 → 部分窗贴 UI → **最终 YOLO 训练数据**

## 用法

```powershell
cd mxd_tools
pip install Pillow

python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原
```

默认约 **80×15 = 1200** 张窗口图（15% val）。

## 默认密度与地板模式（v2）

| 对象 | 规则 |
|------|------|
| 玩家 | 每张大图 **3~4**（地板）+ **1~2** 攀爬 |
| 蓝蜗牛 / 绿蜗牛 / 红蜗牛 / 树怪 / 花蘑菇 | 正常大地板：**2~4 / 2~4 / 1~3 / 2~4 / 2~3** |
| 掉落物 | 正常或仅掉落地板：**2~4**（金币/药水偏多，装备/武器偏少） |
| 入口/出口 | 每张大图 **1~2** |
| UI | `--ui-ratio` 默认 65% |
| 精灵互遮 | ≤ **30%** |
| 过小掉落框 | 窗口内宽或高 &lt; 14px 的掉落标签会丢弃 |

大地板模式权重：正常 55% / 稀疏 25% / 仅掉落 10% / 空台 10%。

**怪物素材**（`assets/mobs`，已抽取才会贴图）：

| 目录 | 标注类 |
|------|--------|
| `1210102_花蘑菇` | 花蘑菇 |
| `100101_蓝蜗牛` | 蓝蜗牛 |
| `100100_绿蜗牛` | 绿蜗牛（客户端无图集时用 IO 回退抽取） |
| `130101_红蜗牛` | 红蜗牛 |
| `130100_树怪` 或 `130100_木妖` | 树怪 |

抽取命令示例：`python scripts/extract_sprites.py --mob 100100`

掉落资源：`assets/drops/`（见 `docs/如何抽取掉落物精灵图.md`）。

## 类别（data.yaml，21 类）

`地板, 梯子, 绳子, 入口, 出口, 花蘑菇, 蓝蜗牛, 绿蜗牛, 红蜗牛, 树怪, 玩家, 金币, 药水, 武器, 装备, 材料, 小地图, 任务窗, 浮动按钮, 面板, 键盘`

## 输出

`dataset/<图名>/generated/yolo/`（images + labels + data.yaml）。

生成后请**重新训练** YOLO（类别数已增至 21，含绿蜗牛）。训练见：`docs/如何训练YOLO模型.md`。

## 掉落/小目标误检说明

装备、药水等小掉落物在游戏里本就很小，易与 UI 纹理、地面细节混淆。生成侧已：降低「仅掉落」场景比例、减少装备抽样权重、过滤过小掉落框。推理侧可配合 `conf` 阈值与「怪离地过高则过滤」规则（见 `docs/代码推理和游戏方式说明.txt`）。
