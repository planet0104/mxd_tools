# 自动贴图标注生成 YOLO 数据集

依据 `dataset/<图名>/需要自动贴图标注的部分说明.txt`：

1. 保留已标好的地板 / 梯子 / 绳子  
2. 在完整大图地板上随机贴入口、出口、怪、掉落物、玩家  
3. 大地板混合四种模式：正常 / 稀疏 / 仅掉落 / 空台  
4. 生成多张大图副本 → 按窗口裁切 → 部分窗贴 UI → **最终 YOLO 训练数据**

## 用法

```powershell
cd mxd_tools
pip install Pillow

python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原
```

默认约 **80×15 = 1200** 张窗口图（15% val）。常用参数：

```powershell
python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/彩虹岛-南港西郊平原 `
  --full-maps 80 `
  --crops-per-map 15 `
  --ui-ratio 0.65 `
  --drops-per-large-min 6 --drops-per-large-max 10 `
  --seed 42
```

## 默认密度与地板模式

| 对象 | 规则 |
|------|------|
| 玩家 | 每张大图 **3~4**（地板）+ **1~2** 攀爬 |
| 蓝蜗牛 / 树怪 / 花蘑菇 | 正常大地板：2~3 / 1~2 / 1~2 |
| 掉落物 | 正常或仅掉落地板：**3~5**（金币/药水/材料/武器/装备） |
| 入口/出口 | 每张大图 **1~2**（最多两个） |
| UI | `--ui-ratio` 默认 65% |
| 精灵互遮 | ≤ **30%** |

大地板模式权重：正常 50% / 稀疏 20% / 仅掉落 20% / 空台 10%。

掉落资源：`assets/drops/`（见 `docs/如何抽取掉落物精灵图.md`）。

## 类别（data.yaml）

`地板, 梯子, 绳子, 入口, 出口, 花蘑菇, 蓝蜗牛, 树怪, 玩家, 金币, 药水, 武器, 装备, 材料, 小地图, 任务窗, 浮动按钮, 面板, 键盘`

## 输出

`dataset/<图名>/generated/yolo/`（images + labels + data.yaml）。

训练见：`docs/如何训练YOLO模型.md`。
