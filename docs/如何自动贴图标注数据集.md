# 自动贴图标注生成 YOLO 数据集

依据 `dataset/<图名>/需要自动贴图标注的部分说明.txt`：

1. 保留已标好的地板 / 梯子 / 绳子  
2. 在完整大图地板上随机贴入口、出口、怪、掉落物、玩家  
3. 大地板混合四种模式：正常 / 稀疏 / 仅掉落 / 空台  
4. 生成多张大图副本 → 按窗口裁切 → 部分窗贴 UI → **最终 YOLO 训练数据**

## 用法

```powershell
cd mxd_tools
pip install Pillow

python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/nangang_50001
```

默认约 **80×15 ≈ 1200** 张窗口图（15% val）。常用参数：

```powershell
python .\scripts\auto_annotate_dataset.py `
  --dataset dataset/nangang_50001 `
  --full-maps 80 --crops-per-map 15 --ui-ratio 0.65 --seed 42
```

## 底图标注（地板 / 绳 / 梯）

脚本读取 `dataset/<图名>/map_*_render_cn.json`（LabelMe）。南港西郊平原（50001）的底图标注由 WZ/网站碰撞同步而来：

| 步骤 | 说明 |
|------|------|
| 碰撞源 | `assets/maps/50001/map_50001_platforms.json`（maplestory.io `GMS/83/map/50001` 的 foothold / ladderRope） |
| 同步脚本 | `python scripts/sync_labelme_from_platforms.py` |
| 当前约定 | 地板顶边=站立线；梯子宽 **50px**；绳子/梯子**底部裁 20px**（去空白，利于 YOLO） |

叠图核对：`tmp/platform_overlay_50001.png`、`tmp/labelme_synced_overlay_50001.png`。

改完 LabelMe 后需**重新跑**本脚本，才会进入训练集。

## 默认密度与地板模式

| 对象 | 规则（默认） |
|------|----------------|
| 玩家（地面站立/走跳） | 每张大图 **6~8** |
| 玩家（攀爬） | **2~4**（贴绳子/梯子，优先 `ladder`/`rope` 帧） |
| 玩家（半空跳跃） | **2~4**（脚底抬离地板） |
| 玩家（战斗） | **2~4**（`swing`/`stab`/`shoot`，优先 O1/O2） |
| 蓝蜗牛 / 绿蜗牛 / 红蜗牛 / 树怪 / 花蘑菇 | 正常大地板：**2~4 / 2~4 / 1~3 / 2~4 / 2~3** |
| 掉落物 | 正常或仅掉落地板：**4~8**（金币/药水偏多） |
| 入口/出口 | 每张大图 **1~2** |
| UI | `--ui-ratio` 默认 65% |
| 精灵互遮 | ≤ **30%** |
| 过小掉落框 | 窗口内宽或高 &lt; 14px 的掉落标签会丢弃 |

大地板模式权重：正常 **45%** / 稀疏 **20%** / 仅掉落 **25%** / 空台 **10%**。

**玩家素材**（`assets/player/<预设>/`，6 套预设）：

| 帧前缀 | 用途 |
|--------|------|
| `stand` / `walk` / `jump` / `alert` | 地面玩家 |
| `ladder` / `rope` | 攀爬玩家 |
| `swing*` / `stab*` / `shoot*` | 战斗玩家（缺则跳过战斗贴图） |

**怪物素材**（`assets/mobs`，已抽取才会贴图）：

| 目录 | 标注类 |
|------|--------|
| `1210102_花蘑菇` | 花蘑菇 |
| `100101_蓝蜗牛` | 蓝蜗牛 |
| `100100_绿蜗牛` | 绿蜗牛（客户端无图集时用 IO 回退抽取） |
| `130101_红蜗牛` | 红蜗牛 |
| `130100_树怪` 或 `130100_木妖` | 树怪 |

抽取命令示例：`python scripts/extract_sprites.py --mob 100100`

掉落资源：`assets/drops/`（见 `docs/如何抽取掉落物精灵图.md`）。  
传送门：`assets/portals/pv_可见传送门/`。  
UI：`assets/ui/*_UI.png`。

## 类别（data.yaml，21 类）

`地板, 梯子, 绳子, 入口, 出口, 花蘑菇, 蓝蜗牛, 绿蜗牛, 红蜗牛, 树怪, 玩家, 金币, 药水, 武器, 装备, 材料, 小地图, 任务窗, 浮动按钮, 面板, 键盘`

## 输出

`dataset/<图名>/generated/yolo/`（images + labels + data.yaml）。  
中间大图：`generated/full_maps/`。摘要：`generated/README.txt`。

最近一次完整生成（`--full-maps 80 --crops-per-map 15 --seed 42`）约 **1199** 窗（train≈1019 / val≈180），21 类齐全；梯子/绳子随更新后的 LabelMe 进入裁切标签。

生成后请**重新训练** YOLO。训练见：`docs/如何训练YOLO模型.md`。

## 掉落/小目标误检说明

装备、药水等小掉落物在游戏里本就很小，易与 UI 纹理、地面细节混淆。生成侧已：降低「仅掉落」场景比例、减少装备抽样权重、过滤过小掉落框。推理侧可配合 `conf` 阈值与「怪离地过高则过滤」规则（见 `docs/代码推理和游戏方式说明.txt`）。
