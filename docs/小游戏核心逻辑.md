# 小游戏核心设计文档（MVP + NEAT 训练预备）

**最终目的**：

1. **窗口模式**：可玩的冒险岛怀旧风小游戏——键盘打怪，底部贴 `assets/ui_game` 原版底框，尽量贴近正式客户端布局。
2. **无头模式**（后续）：同逻辑、同画面布局，多实例全速跑帧，供 YOLO + OCR 识别 + NEAT 进化训练。

**技术建议**：`mxd_tools` 新增库 `src/game/` + 二进制 `mini_game`（窗口）/ `mini_game_headless`（无头）；渲染用 **macroquad**（轻量、易离屏渲染）；逻辑与渲染分离，便于 NEAT 多开。

---

## 0. 分阶段交付

| 阶段 | 目标 | 验收 |
|------|------|------|
| **P0** | 窗口 + 地图 + 玩家走跳 + 底部 UI 壳 | 1368×768 窗口，能看到地图和贴好的面板 |
| **P1** | 打怪闭环 | 普攻、怪巡逻/死亡、掉金币、HP 在面板上显示 |
| **P2** | 背包吃药 | 打开物品栏，点击/快捷键喝红药回血 |
| **P3** | 无头加速 | `--headless --fps 0` 多实例，输出与窗口一致的 RGB 帧 |

P0～P1 是「先跑起来能玩」；P2 是吃药；P3 为 NEAT 服务，**架构从 P0 就要预留**。

## 1. 画面布局（与 `screen_caps` / `assets/ui` 对齐）

窗口总分辨率：**1368 × 768**（与现有截图、YOLO 数据集一致）。

```
┌──────────────────────────────────────────── 1368 ────────────────────────────────────────────┐
│ [小地图]                                                          [任务窗]                  │  ← UI 层（贴图）
│ [浮动按钮]                                                                                  │
│                                                                                             │
│                     游戏世界视口（World Viewport）                                           │
│                     相机跟随玩家，绘制地图+实体                                               │
│                     高度 = 768 - panel_h（约 520～560px）                                    │
│                                                                                             │
│                                                                          [键盘]             │
├─────────────────────────────────────────────────────────────────────────────────────────────┤
│                              [面板_UI]  HP / MP / 经验 / 快捷栏                               │  ← 底部固定
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.1 UI 资源

| 目录 | 用途 |
|------|------|
| `assets/ui/` | **截图裁切**，供 YOLO / `auto_annotate_dataset` 训练，勿覆盖 |
| `assets/ui_game/` | **客户端原版底框**（`extract_ui_hud.py`），`mini_game` **只读这里** |

| `ui_game` 文件 | 来源 | 锚点 |
|----------------|------|------|
| `minimap_frame.png` | MiniMap MaximizeBackground 九宫格合成 | `(6, 6)` |
| `keyboard_frame.png` | StatusBar ShortCutKeys/quickSlot | 面板右上外侧 |
| `panel_frame.png` | StatusBar LayerSkin/Background backgrnd | 底部居中贴底 |

重新抽取：`python scripts/extract_ui_hud.py`。

窗口过窄时整套 UI **等比缩小**（复用 `scale_ui_set` 逻辑）。

### 1.2 世界视口 vs UI

- **世界层**：只画地图、怪、掉落、玩家；相机 `(cam_x, cam_y)` 跟随玩家。
- **UI 层**：每帧最后绘制，**屏幕坐标**，不随相机移动。
- **游戏区域高度**：`world_h = window_h - panel.height`（键盘叠在世界里、贴面板上方，与正式客户端一致）。
- **玩家 Y 限制**：脚点不得超过 `world_h - 8`，避免角色画进面板区。

> 实现要点：两套坐标系——`world`（地图像素）与 `screen`（窗口像素）。NEAT/YOLO 的截图应对 **整窗 1368×768**（含 UI），与 `screen_caps` 一致。

## 3. 操作方式

### 3.1 移动与战斗（P1）

| 操作 | 按键 | 规则 |
|------|------|------|
| 左右移动 | `←` / `→` | 水平速度；面向翻转 |
| 跳跃 | `Alt` / `Space` | 地面起跳，无二段跳 |
| 攻击 | `Ctrl` / `J` | 身前攻击框，冷却 0.35s |
| 拾取 | `Z` | 距掉落物 < 32px 拾取进背包 |
| 上/下梯绳 | `↑` / `↓` | 见 §6 |

### 3.2 物品与吃药（P2）

| 操作 | 按键 | 规则 |
|------|------|------|
| 打开物品栏 | `I` / 点面板「背包」热区 | 弹出窗口，**暂停或半透**均可；MVP 建议暂停游戏逻辑 |
| 使用红药 | 物品栏内点击 / 快捷栏 `1` | 消耗 1 瓶，HP +30，关闭窗口或保持打开 |
| 关闭物品栏 | `Esc` / `I` | 回到游戏 |

**逻辑分离**：`use_item(ItemId::RedPotion)` 同时服务键盘、UI 点击、以及日后 NEAT 的 `Action::UsePotion`。

## 5. 碰撞与战斗（摘要）

- 玩家碰怪：扣 HP + 击退 + 无敌。
- 玩家攻击：身前 48×36 框，怪 HP 归零 → 死亡动画 → 掉落。
- 怪 AI：在刷怪平台连续段内巡逻，移速按 Mob.wz `speed` 换算，边缘转身；**不做追击**。

## 8. 架构（为窗口 + 无头共用）

```
┌─────────────────────────────────────────────────────────┐
│  mini_game / mini_game_headless / neat_worker (bin)      │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  GameSession                                             │
│  ├─ GameSim（纯逻辑，无 GPU）                              │
│  │    tick(fixed_dt, InputFrame) → GameState             │
│  ├─ InputSource trait                                     │
│  │    KeyboardInput | ScriptedInput | NeatPolicyInput    │
│  └─ GameView（渲染）                                      │
│       draw_world + draw_ui → Texture / RGB buffer         │
└─────────────────────────────────────────────────────────┘
```

### 8.1 固定时间步（NEAT 必做）

- 逻辑：**60 Hz** 固定步长 `dt = 1/60`，与显示帧率解耦。
- 渲染：窗口模式可 60fps 显示；无头模式 `sim_ticks_per_frame` 可设为 1，**不等待垂直同步**。
- 随机：**显式 `rng_seed`**，同种子同输入 → 同结果（刷怪、掉落用 `StdRng`）。

### 8.2 输入抽象（NEAT 必做）

```rust
struct InputFrame {
    left: bool,
    right: bool,
    jump: bool,
    attack: bool,
    up: bool,
    down: bool,
    pick_up: bool,
    use_potion: bool,      // P2 / 快捷栏
    open_inventory: bool,  // P2
    inventory_click: Option<(u32, u32)>, // 屏幕坐标，P2
}
```

- 窗口：`macroquad` 键盘 → `InputFrame`
- NEAT：网络输出离散动作 → 映射为 `InputFrame`（见 §13）
- **禁止**在 `GameSim` 内直接读键盘

### 8.3 渲染与截图（YOLO / OCR 对齐）

- 输出尺寸固定 **1368×768 RGB8**。
- 绘制顺序：清屏 → 世界（相机变换）→ UI 贴图 → 动态条/文字 → 物品栏（若打开）。
- 提供 API：

```rust
fn render_frame(&self, view: &mut GameView) -> RgbImage;  // 整窗
fn world_viewport(&self) -> Rect;  // 供只裁游戏区做检测时用
```

无头模式每 N 逻辑帧导出一张图，或按需 `snapshot()` 给 YOLO 管线。

### 8.4 模块划分

| 模块 | 路径建议 | 职责 |
|------|----------|------|
| `game::sim` | 纯 Rust | 物理、AI、战斗、背包、状态机 |
| `game::assets` | 加载 PNG、动画表 | |
| `game::map` | 平台/绳梯 | |
| `game::ui` | 面板布局、HP 条、物品栏 | |
| `game::view` | macroquad 绘制 | |
| `game::input` | Keyboard / Virtual | |

`find_player` 用的 YOLO/OCR **不嵌进游戏循环**；训练侧读 `render_frame()` 输出即可。

## 9. 物品栏与吃药（P2 细则）

1. **背包数据结构**：`HashMap<ItemId, u32>`，至少 `RedPotion`、`Meso`。
2. **拾取**：地上红药 → `RedPotion += 1`；金币 → `Meso += n`（只改数据，可不在物品栏显示金币）。
3. **打开物品栏**：`GameState.modal = Inventory`；绘制半透明遮罩 + 网格；显示药水图标与数量。
4. **使用**：点击格子或按 `1` → 若 `RedPotion > 0` 且 `HP < max` → 消耗 1，HP +30。
5. **与 NEAT**：动作 `UsePotion` 等价于按 `1`，不要求学会打开 UI（降低难度）；高级策略可再加 `OpenInventory`。

## 10. 无头模式与 NEAT 训练（P3）

### 10.1 运行方式（目标）

```powershell
# 单实例压测
cargo run --release --bin mini_game_headless -- --seed 42 --ticks 3600 --dump-every 10

# 并行（示意，后续用进程池）
# 每个 worker：独立 GameSession(seed+i)，全速 tick，按需写帧或只回传 fitness
```

### 10.2 性能要点

| 要点 | 说明 |
|------|------|
| 无窗口 | `macroquad` conf 设 `window_mode: MINIMIZED` 或离屏 `texture` 渲染到内存 |
| 禁 VSync | `vsync: false` |
| 少分配 | 纹理/精灵 **启动时** 加载一次，sim 内不 `load_texture` |
| 可跳帧绘制 | 训练只要偶发截图时，`ticks` 之间不必每步 `render` |
| 多进程 | 每进程 1 个 ORT/YOLO 太重 → **NEAT 只吃游戏内置状态** 或 **降频** 调 YOLO；或 YOLO 只用于离线标注，在线 NEAT 用 `GameState` 向量观测 |

### 10.3 观测与动作（NEAT 接口草案）

**观测向量（示例，免 CNN 也能训）**：

- 玩家：归一化 HP、vx、vy、on_ground、facing
- 最近 3 只怪：相对 dx、dy、hp_ratio（不足补 0）
- 最近掉落：dx、dy、type_onehot
- 背包：red_potion_count

**离散动作（示例）**：

`Noop | Left | Right | Jump | Attack | PickUp | UsePotion`

NEAT 输出 → `InputFrame`；每逻辑帧一步。

### 10.4 与 YOLO + OCR 的关系

| 用途 | 做法 |
|------|------|
| 生成训练数据 | 无头 `dump` 1368×768 帧 + 自动标玩家框（sim 内有 ground truth） |
| 玩正式游戏 | 窗口模式人工玩 |
| NEAT 读屏玩 | 慢：每步截图 → YOLO 找玩家 → OCR 找血条/药（**不推荐内循环**） |
| NEAT 推荐 | **内置状态向量** 训练；YOLO/OCR 仅用于验证「像不像真客户端画面」 |

文档约定：**游戏 sim 提供 ground truth API**（`player_xy`, `hp`, `mobs[]`），方便对照 YOLO 精度，而不是让 NEAT 每帧跑 ONNX。
